## Archived (no longer maintained)

- [@tkesgar/lazy]: lazy value container
  - No alternative at the moment, although I often copy-pasted the code directly
    into my projects if I need it.
- [acall]: helper to enforce async error handling
  - No alternative, please handle your errors properly
- [@tkesgar/reine]: SWR cache function
  - No direct alternative, but Nitro/Nuxt have
    [cachedFunction and cachedEventHandler](https://nitro.build/guide/cache)
- [@tkesgar/reno]: .env file loader
  - Node.js has
    [native .env support since v20](https://nodejs.org/docs/v24.5.0/api/environment_variables.html#env-files)
  - Bun has [native .env support](https://bun.com/guides/runtime/read-env)
  - Some frameworks such as Next.js and Nuxt also loads .env files
- [@tkesgar/ariadoa]: simulate request to Express middlewares for testing
  - Use [supertest] instead
